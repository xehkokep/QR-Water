# QR-Water: QR-коды оборудования

Приложение для ежемесячного обхода магазинов. Хранит фотографии QR-кодов оборудования, раскладывает их по дням недели, показывает на весь экран для сканирования и отмечает, что уже отсканировано.

Работает на iPhone и Android прямо из браузера, ничего устанавливать из магазина приложений не нужно. После первого открытия работает и без интернета.

Адрес приложения: https://xehkokep.github.io/QR-Water/ (точный адрес смотрите в Settings → Pages).

## Установка на телефон

**iPhone (только Safari):**
1. Откройте ссылку в Safari.
2. Нажмите «Поделиться» (квадрат со стрелкой).
3. Выберите «На экран Домой», затем «Добавить».

**Android (Chrome):**
1. Откройте ссылку в Chrome.
2. Нажмите меню (три точки).
3. Выберите «Установить приложение» или «Добавить на главный экран».

Дальше открывайте приложение только с иконки на главном экране. На iPhone это важно: в обычном Safari сохранённые коды могут быть стёрты, если сайт долго не открывали.

## Главный экран

- **Вкладки сверху:** Все, Пн–Вс, Без дня. Рядом с названием стоит число кодов в этом дне. При запуске открывается вкладка сегодняшнего дня.
- **Строка поиска:** ищет по названию оборудования и по магазину.
- **Полоска «Отсканировано N из M»:** показывает прогресс по выбранной вкладке.
- **Список:** каждая строка это один код: картинка, название оборудования, магазин и круглая галочка справа.
- **Кнопка «+ Добавить QR»:** внизу справа.
- **Кнопка «Новый месяц»:** сверху справа, сбрасывает все отметки (см. ниже).

## Добавить один QR-код

1. Нажмите «+ Добавить QR».
2. Нажмите «Сфотографировать» или «Из галереи» и выберите снимок кода.
3. Впишите название оборудования (например, «холодильник №2») и магазин.
4. Выберите день. По умолчанию стоит «Без дня».
5. Нажмите «Сохранить».

Снимайте код ровно и крупно, чтобы он хорошо читался с экрана.

## Загрузить целый лист с кодами

Если у вас есть напечатанный лист с наклейками (по 16 штук), быстрее загрузить его целиком.

1. Нажмите «+ Добавить QR», затем «Загрузить целый лист».
2. Выберите фото листа.
3. Нажмите «Повернуть», пока надписи не станут читаться прямо (не вверх ногами и не боком).
4. Растяните рамку за красные точки (левый верхний и правый нижний углы) так, чтобы линии сетки легли между наклейками. Рамку можно двигать пальцем.
5. Если лист снят с перекосом или в нём другое число кодов, откройте «Настройки сетки»: там наклон, число столбцов и число строк. По умолчанию 4 столбца и 5 строк.
6. Нажмите «Нарезать».
7. Приложение разрежет лист на отдельные коды и само прочитает название магазина с каждой наклейки. Проверьте названия, исправьте неверные и впишите название оборудования.
8. Снимите галочку слева у ненужных кодов, выберите «День для всех» и нажмите «Сохранить всё».

Как работает чтение названий:
- Приложение читает надпись над кодом. Название оборудования на наклейках не напечатано, его вписываете вы.
- Если название прочитано неверно, исправьте его в одной строке. Остальные похожие названия на этом листе поправятся сами.
- Раз вписанные магазины запоминаются: на следующих листах они будут узнаваться автоматически.
- Чтение занимает от десяти секунд до минуты. Прогресс виден над списком, править поля можно, не дожидаясь конца.

## Сканирование

1. Откройте вкладку нужного дня.
2. Нажмите на строку, и код откроется на весь экран на белом фоне. Наведите на него сканер.
3. Нажмите «Отсканирован». Код получит отметку, и откроется следующий.
4. Листать коды можно без отметки: проведите пальцем влево или вправо, либо нажмите ‹ и ›. Счётчик показывает «3 из 16».
5. Отметить код можно и в списке: нажмите на круглую галочку справа.
6. Если отметили по ошибке, откройте код и нажмите «Снять отметку».

## Порядок по маршруту

Во вкладке конкретного дня слева у каждой строки есть значок ≡. Зажмите его и перетащите строку вверх или вниз. Порядок запоминается и совпадает с порядком листания кодов. Новые коды добавляются в конец списка.

Во вкладке «Все» перетаскивать нельзя, потому что там коды идут по дням.

## Сменить день, изменить, удалить

Откройте код на весь экран:
- **День:** выпадающий список слева внизу.
- **Изменить:** название, магазин, день, можно заменить фото.
- **Удалить:** нажмите дважды. Первое нажатие превращает кнопку в «Точно удалить?», второе удаляет.

## Новый месяц

Нажмите «Новый месяц» вверху и подтвердите повторным нажатием «Сбросить все отметки?». Коды и дни остаются, исчезают только отметки «отсканировано».

## Где хранятся данные

- Все коды хранятся в памяти браузера на этом телефоне. У каждого человека свой список, общего списка нет.
- При смене телефона, очистке данных браузера или удалении иконки с экрана коды пропадут. Копии и переноса между устройствами в приложении нет.
- Ничего не отправляется на сервер: фото остаются на устройстве.

## Обновление приложения

Файлы лежат в этом репозитории. Чтобы обновить приложение:
1. На странице репозитория нажмите «Add file» → «Upload files».
2. Перетащите новые файлы (с теми же именами, что и старые) и нажмите «Commit changes».
3. Через пару минут закройте приложение на телефоне и откройте заново. Если осталась старая версия, обновите страницу.

Состав репозитория:
- `index.html`: само приложение.
- `sw.js` и `manifest.webmanifest`: работа без интернета и установка на экран.
- `icon-*.png`: иконки.
- `ocr/`: файлы для чтения названий с наклеек (около 14 МБ). Без этой папки приложение работает, но названия придётся вписывать вручную.

## Если что-то не работает

- **Названия с листа не читаются, написано «Автоматическое чтение недоступно».** Проверьте, что папка `ocr` загружена в репозиторий целиком.
- **Не видно новых функций после обновления.** Закройте приложение полностью и откройте заново.
- **Не получается перетащить строку.** Тяните именно за значок ≡ слева, а не за название. Значок есть только во вкладках дней.
- **Коды пропали.** Скорее всего, были очищены данные браузера. Вернуть их нельзя, загрузите листы заново.
