# Сканирование ДМП

Приложение для ежемесячного обхода магазинов. Хранит фотографии QR-кодов оборудования, раскладывает их по дням, показывает на весь экран для сканирования и отмечает, что уже отсканировано.

Работает на iPhone и Android из браузера, ничего устанавливать из магазина приложений не нужно. После первого открытия работает и без интернета.

Адрес: https://xehkokep.github.io/QR-Water/ (точный адрес смотрите в Settings → Pages репозитория).

## Установка на телефон

**iPhone (Safari):** откройте ссылку → «Поделиться» → «На экран Домой» → «Добавить».

**Android (Chrome):** откройте ссылку → меню (три точки) → «Установить приложение». Если приложение уже было установлено раньше, удалите иконку и установите заново, иначе останутся старые цвета и иконка.

Дальше открывайте приложение с иконки на главном экране. На iPhone это важно: в обычном Safari сохранённые коды могут быть стёрты, если сайт долго не открывали.

## Главный экран

- **⚙ слева вверху:** настройки.
- **Вкладки:** Все, Пн–Вс, Без дня. Рядом число кодов. При запуске открывается сегодняшний день.
- **Поиск:** по названию магазина. Регистр и похожие русские и латинские буквы не важны.
- **Полоска «Отсканировано N из M»:** прогресс по вкладке.
- **Строка списка:** магазин, значок ХО (если холодильное оборудование), круглая галочка справа.

## Дни и повторы

Коды автоматически дублируются на второй день недели:
- понедельник и четверг;
- вторник и пятница;
- среда и суббота.

Если поставить код на понедельник, он появится и в понедельник, и в четверг. Если на четверг, то тоже в обоих. Воскресенье и «Без дня» не дублируются. Отметка «отсканировано» у каждого из двух дней своя.

## Добавить один код

«+ Добавить QR» → «Сфотографировать» или «Из галереи» → впишите магазин → при необходимости нажмите «ХО · холодильное оборудование» → выберите день (по умолчанию «Без дня») → «Сохранить».

Если магазин уже есть в списке, но написан иначе (другой регистр, похожие буквы), приложение подставит существующее написание, и коды объединятся в один магазин.

## Загрузить целый лист

1. «+ Добавить QR» → «Загрузить целый лист» и выберите фото листа.
2. «Повернуть», пока надписи не станут читаться прямо.
3. Растяните рамку за красные точки так, чтобы линии сетки легли между наклейками. По умолчанию сетка 4 столбца × 5 строк. Столбцы, строки и наклон прячутся под кнопкой «Настройки сетки».
4. «Нарезать». Приложение разрежет лист и прочитает название магазина с каждой наклейки.
5. Проверьте названия. Исправьте неверное один раз, и остальные похожие на листе поправятся сами. У каждого кода есть кнопка «ХО», а «ХО всем» отмечает все сразу.
6. Выберите «День для всех» (по умолчанию «Без дня») и нажмите «Сохранить всё».

## Сканирование

1. Откройте вкладку дня и нажмите на строку, код откроется на весь экран.
2. Нажмите «Отсканирован»: код получит отметку, откроется следующий.
3. Листать можно свайпом влево и вправо или кнопками ‹ и ›. Сверху справа счётчик «3 из 16».
4. Если у кода два дня (например, Пн и Чт), сверху есть две кнопки с днями. Отметка ставится на выбранный день. По умолчанию выбран день вкладки или сегодняшний.
5. «Все коды магазина (N)» показывает все коды этого магазина по всем дням, где N это их число. Листать их можно так же. «Вернуться к списку» возвращает обычный список.
6. Отметку можно снять: «Снять отметку».
7. В списке отметить код можно круглой галочкой справа.

## Порядок по маршруту

Во вкладке дня слева у каждой строки значок ≡. Зажмите его и перетащите строку. Порядок запоминается и совпадает с порядком листания. Новые коды добавляются в конец. Во вкладке «Все» перетаскивать нельзя.

## Изменить, сменить день, удалить

Откройте код на весь экран: выпадающий список дней (полные названия), «Изменить» (магазин, ХО, день, фото), «Удалить» (двойное нажатие). При смене дня отметки этого кода сбрасываются.

## Настройки

- **Тема:** тёмная (по умолчанию) или светлая.
- **Статистика за месяц:** сколько отсканировано, первое и последнее сканирование, за какое время отсканировано всё, скорость (кодов в час), дней сканирования, среднее и лучший день, разбивка по дням недели.
- **Сбросить все отметки:** двойное нажатие.
- **Обратная связь:** открывает письмо на xehkokep@gmail.com. Нажмите «Отправить» в почтовом приложении.

Статистика и отметки сбрасываются сами 1-го числа каждого месяца, при первом открытии приложения в новом месяце.

## Где хранятся данные

- Всё хранится в памяти браузера на этом телефоне. У каждого свой список, общего списка нет.
- При смене телефона, очистке данных браузера или удалении иконки коды пропадут. Копий и переноса между устройствами нет.
- Ничего не отправляется на сервер.

## Обновление приложения

1. На странице репозитория: «Add file» → «Upload files».
2. Перетащите новые файлы с теми же именами и нажмите «Commit changes».
3. Через пару минут закройте приложение на телефоне и откройте заново.

Файлы репозитория:
- `index.html`: само приложение.
- `sw.js`, `manifest.webmanifest`: работа без интернета и установка.
- `icon-180.png`, `icon-192.png`, `icon-512.png`: иконки.
- `ocr/`: файлы для чтения названий с наклеек (около 14 МБ). Без неё всё работает, но магазины нужно вписывать вручную.

## Если что-то не работает

- **«Автоматическое чтение недоступно».** Проверьте, что папка `ocr` загружена целиком.
- **Не видно новых функций.** Закройте приложение полностью и откройте заново.
- **Не перетаскивается строка.** Тяните за значок ≡ слева. Он есть только во вкладках дней.
- **Коды пропали.** Скорее всего, были очищены данные браузера. Загрузите листы заново.
